# ANA特典航空券プランナー

[公開サイト](https://mimausr-hub.github.io/ana-award-planner/) · HTML/CSS/JavaScriptの静的PWA。seats.aeroのキャッシュから、ANA公式で照合する候補を作ります。予約・発券やANAのログイン自動化は行いません。

## 2026-10-18の精度改善

- 提供元ごとに席数と観測時刻をセットで保持。異なるプログラムの最大席数・最新時刻を合成しません。同じ提供元では最新の観測を採用します。
- 運航会社自身の会員枠を、他社提携枠の席数として使いません。人数条件を満たす提供元を選び、その提供元の時刻で評価します。
- 席数0・未提供は「不明」。人数分を満たすとは扱わず、通常は除外します。時刻不明・未来の観測時刻も新鮮なデータとして評価しません。
- 既定の「根拠の揃う候補に絞る」は、人数分・72時間以内の観測・他社提携プログラムの根拠がある便に限定します。参考候補を見る場合はOFFにできます。席数不明は別途チェックが必要です。
- 確認優先度は最も弱い区間を中心に評価。「根拠が比較的強い」は全区間で24時間以内の複数提供元が人数条件に一致する場合です。成功率やANA予約可の判定ではありません。すべてANA公式未確認として表示します。
- 出発地・帰着地を選択都市に限定。関西・中部などの便を東京発と混同せず、地方発を探す場合は出発地を変更します。国内線や空港までの移動は自動追加しません。
- 同一空港のみで接続。空港移動を含む90分乗継や過去日の便を候補から除外します。
- ANA提携特典のエリア制限、乗換地点まで／乗換地点から目的地までのマイル数、途中降機、対象クラス・会社の制限を確認します。欧州行きの北米経由、北米行きのソウル経由、LX/SQファースト、提携便プレミアムエコノミー等を除外します。
- 提携航空会社の直行便も探索。TG成田→バンコク等、目的地がハブと一致する直行便の取りこぼしを修正しました。
- ANA通常必要マイルを2025-06-24改定後の公式値に更新。シーズンは地域・年度別の公表日付を使用し、未登録年は推定しません。片道は片道マイルで表示。候補詳細のマイルは実際の候補日と直行／海外乗継で算出します。
- 候補に優先して照合する便、人数条件の不一致、VN/SQの注意点、途中降機の制約などをコメントとして表示。検索画面に公式リンクと探すコツ、日付を明記した検証例を追加しました。

### 判定の限界

往路と復路は独立した候補です。往復全体の日付順、途中降機合計、運航会社の組み合わせ、必要乗継時間、通し発券可能性はANA公式で確認してください。全区間・人数・クラス・必要マイル・税金料金と確認日時が揃うまで、販促上も予約可能と確定できません。

他プログラムでの観測はANAの空席保証ではありません。再取得しても提供元の観測時刻が更新されるとは限りません。ANA会員向け枠やseats.aero未収録の便があるため、候補ゼロをANAの空席ゼロとは判定しません。航空会社別の成功率や空席開放パターンの統計学習は未実施です。

燃油は従来の概算で、税金・料金の総額ではありません。日付別の減額キャンペーン等も自動適用しません。過去の手入力チャートは保存を残したまま、現行の公式値を優先します。設定画面で再保存したチャートには `rulesVersion: 2` を付けて適用します。

`data.js` の `anaChart` は往復値（片道は半分）。`anaSeasons` はasia/west/pacific別の公表期間。`partnerZoneChart` は提携の往復値で、1-Aは直行、1-Bは海外乗継の参考値です。往復に1区間でも海外乗継を足すと全体で1-Bになるため、片道候補の金額を無条件に合算しません。

## 検索・接続

ANAとスターアライアンスを中心に、VNは参考候補として探索します。オプションでエコノミーへの再探索とJAL・ワンワールドも表示します。全社の各区間をまとめて取得し、2〜3便の乗継を作成。会社をまたぐ乗継は表示上限があり、全旅程の網羅は保証しません。

片側の日付だけ変更した場合は、同条件の側の取得結果を6時間まで再利用。「全部取り直す」で破棄します。API使用状況はこの端末の回数と、提供元が返す残数を表示します。

初回は合言葉でログインします。合言葉をサーバーで検証後、ブラウザに保存。APIキーによるログインやURLでの秘密情報共有はできません。共有は通常URLと合言葉を別々に伝えてください。

公開サイトの中継はCloudflare Workerです。設定とデプロイは [worker/README.md](worker/README.md)。GitHub Pagesはmainブランチのルートから公開しています。フロントの更新時は `index.html` の資産バージョンと `sw.js` のキャッシュ・資産一覧を揃えて更新します。

## ローカル起動・検証

```sh
python3 serve.py
# http://127.0.0.1:8765/
```

ローカルAPIキーは環境変数 `SEATS_AERO_KEY` または `.seats_aero_key`（gitignore済）で設定。APIキー・合言葉・会員情報をリポジトリに保存しないでください。

```sh
SEATS_AERO_MOCK=1 PORT=8766 python3 serve.py
node --test tests/accuracy.cjs tests/smoke.cjs
```

モックは画面確認用の架空便です。実際の便・空席ではなく、画面にもサンプル表示が出ます。テストは提供元の混同、人数・鮮度、未知値、禁止旅程、直行便、公式マイル・シーズンと既存ログイン保護を検証します。

## seats.aero API

seats.aero Pro APIは非商用利用が条件。商用利用はseats.aeroとの書面合意が必要です。詳細は提供元の現行利用条件を確認してください。
